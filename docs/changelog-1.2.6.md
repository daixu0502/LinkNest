# LinkNest 1.2.6

- 增加可选的「信任此浏览器 24 小时」：成功验证后固定到期，登录会话仍为 8 小时；敏感操作继续校验管理员密码。信任凭据使用独立 HttpOnly Cookie，服务端只保存哈希；退出、撤销及账户安全变更按规则使信任失效。
- 信任过期时，在原操作弹窗补充验证码输入并保留已填写内容。保留验证码防重放、来源校验与限流。
- 手机与触屏轻面板采用整页滚动，页头、搜索和筛选随页面滚出；完善安全区、触控尺寸、背景底色与图片加载失败回退。
- 修复桌面轻面板右侧纯色色条：取消多余的文档滚动槽，保留卡片区域滚动和滚动条。
- 构建工具链升级到 Go 1.26.11，修复官方漏洞扫描识别的 HTTP 标准库问题。

手机背景保持已部署版本的处理方式。Safari 状态栏、底部工具栏及页面回弹区域的最终绘制由浏览器控制，本版本不包含额外的上下边缘渐变处理。

配置 schema 保持 5。升级前备份完整数据，使用原容器参数与数据卷重建；不要删除数据卷。Go、浏览器、双架构运行时及备份回滚验收均在本机 WSL Docker 执行，测试与凭据仅保留本地。
