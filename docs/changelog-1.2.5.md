# LinkNest 1.2.5

- 修复总览「证书有效期」「域名同步」列表仍使用旧式深色悬停背景的问题；按钮式导航链接纳入共享反馈。
- 同步统一统计卡片、网络服务、连接与安全及待处理事项的悬停、键盘焦点和按下效果；状态标签保留成功、警告和错误配色。
- 删除管理界面和公共轻面板中被共享反馈替代的旧悬停背景、亮度滤镜、重复焦点及未使用的统计链接样式。保留普通正文链接、站点卡片动效、危险操作和选项卡选中指示器。
- 发布流程增加显式「仅发布」模式：仍需完整 WSL 验收、源码一致性、双架构镜像及回拉检查，但不再为了发布而强制部署或重启生产实例。部署验证模式继续要求对应候选的路由器记录。
- 发布工具可直接从 Windows 工作区的 WSL 挂载目录运行，支持复用用户在 WSL 中完成的 Docker 登录，不复制、输出或提交凭据。

配置 schema 保持 5；本版本未修改业务配置格式。
